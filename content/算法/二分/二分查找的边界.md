二分查找写错的地方几乎都在边界上。把区间定义成左闭右闭 `[lo, hi]`，循环条件就是 `lo <= hi`，收缩时 `hi = mid - 1`；定义成左闭右开 `[lo, hi)`，循环条件就是 `lo < hi`，收缩时 `hi = mid`。

## 两种写法

只要在整段代码里坚持一种定义，就不会出现死循环或者漏掉最后一个元素。

```cpp
int lower_bound(vector<int>& a, int x) {
  int lo = 0, hi = (int)a.size();
  while (lo < hi) {
    int mid = lo + (hi - lo) / 2;
    if (a[mid] < x) lo = mid + 1;
    else hi = mid;
  }
  return lo;
} ^code-lb
```

## 常见坑

- `mid = (lo + hi) / 2` 在 `lo + hi` 溢出时会变成负数，写成 `lo + (hi - lo) / 2`。
- 找「最后一个满足条件的」和「第一个满足条件的」是两个不同的模板，不要混用。
- 答案在实数域时，循环 `100` 次比判断 `eps` 更稳。 ^pitfalls

## 补充：边界怎么写

左右端点差 1 就退出，最后答案看是哪一边。
