树状数组用 `lowbit` 把下标跳成二进制的最低位，单点改和前缀和都是 `O(log n)`。

## 核心三行

```cpp
int lowbit(int x) { return x & -x; }
void add(int i, int v) { for (; i <= n; i += lowbit(i)) tr[i] += v; }
int sum(int i) { int s = 0; for (; i; i -= lowbit(i)) s += tr[i]; return s; }
```
