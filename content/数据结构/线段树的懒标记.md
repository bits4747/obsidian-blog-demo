区间修改需要懒标记：把「这个区间整体加了多少」先记在节点上，等真正要往下走的时候再推给孩子。

## 两个函数

`pushdown` 负责把标记下传，`pushup` 负责用孩子的值更新父亲。写的时候要保证：

- 打标记时同时更新该节点自己的答案；
- 下传后清空父节点标记；
- 叶子节点不再下传。

```cpp
void apply(int p, int v, int len) {
  tr[p] += v * len;
  tag[p] += v;
}
void pushdown(int p, int l, int r) {
  if (!tag[p]) return;
  int mid = (l + r) >> 1;
  apply(p << 1, tag[p], mid - l + 1);
  apply(p << 1 | 1, tag[p], r - mid);
  tag[p] = 0;
}
```
